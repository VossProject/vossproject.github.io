My Open Source Story

CodePath AI301

This past summer I took CodePath's AI Open Source Capstone. The whole course is one loop: find a real issue in a real open source project, fix it, get it merged, then pick another one. We met every week in small groups for standups, so there was always someone to ask when I got stuck.

Finding an issue

This was harder than I expected. I looked at around 60 issues before I found one I could claim. Most of them already had someone working on a fix, even when the issue looked open. I learned to check for open pull requests first, before reading anything else.

My first merged fix

My first contribution was to LFortran, a compiler for the Fortran language. It was accepting a line of code that should have been an error and quietly ignoring part of it. I don't know Fortran, but the bug was really about error handling, so I could still work on it. I added a check so the compiler shows an error instead.

By the time my fix was ready, the main project had changed a lot, and I had to update my copy and sort out conflicts before it could go in. The maintainers merged it, and now my code is part of the project.

What I learned

Open source is as much about people as it is about code. You're working with maintainers you've never met, so you read how the project does things, introduce yourself when you claim an issue, and keep your pull request small and easy to review.
