Getting Involved

You don't have to be an expert

A lot of people think you need to be a senior developer to help with open source. You don't. Some of the most useful help has nothing to do with code.

  • Report a bug when something breaks, with the steps to make it happen again
  • Fix a typo or unclear line in the instructions
  • Translate the app into another language
  • Answer someone else's question

Changing the code

Once you're ready to help with code, the steps on GitHub are pretty simple.

  1. Fork the project, which makes your own copy.
  2. Make your change and test it.
  3. Open a pull request, which asks the owner to add your change to the real project.

The owner might ask for changes first. That's normal, and it's a good way to learn.

Be a good guest

Read the README before jumping in. Many projects also have a contributing guide that explains how they like things done. Most maintainers are volunteers, so being patient and polite goes a long way.
