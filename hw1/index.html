What is Open Source?

The basic idea

Most apps hide their code. You get the finished product, but you can't see how it was made. Open source software is the opposite. The code is public, and anyone can read it, use it, change it, and share it.

I like to think of it as a recipe. A closed app is a meal from a restaurant. An open source app hands you the recipe, and you're free to cook it yourself or swap out an ingredient.

Why do people share their code?

  • More people looking at the code means bugs get found and fixed faster.
  • It's free to use, which matters for students, schools, and small businesses.
  • You can learn a lot by reading code that real people use every day.
  • Anyone can help, so a project can keep going even if the original author moves on.

Each project has a license that sets the rules. Some let you do almost anything. Others ask that if you share a changed version, you keep it open too.

Fun fact: Linux started in 1991 as a hobby project by a college student named Linus Torvalds. Today it runs most of the world's web servers, and every Android phone is built on it.
